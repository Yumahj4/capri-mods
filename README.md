# Restart Capri

Adds a right-click menu item and voice command to restart Capri.

- Made by: Yuma (h.j4.)
- Version: 1.0.1
- Type: Code mod (`.capri-code`)

Use the **Restart Capri** item in a Capri right-click menu, or say or type a phrase such as "restart Capri", "reboot Capri", "relaunch Capri". Capri starts a replacement process and exits the current one.
